# Shigemori's Portfolio

GitHub Pages で公開する、ゲームプログラマー向けのポートフォリオサイトです。Jekyll の `jekyll-theme-minimal` を使い、追加のフォントや画像素材を必要としない構成にしています。

## 公開設定

GitHub リポジトリの **Settings → Pages** で、公開元を `Deploy from a branch`、ブランチを `main`（または既定ブランチ）の `/ (root)` に設定してください。ユーザーサイトの URL は `https://ShigemoriMasato.github.io/` です。

## プロフィールの編集

プロフィールは `index.md` に反映しています。公開する情報を変更する場合は同ファイルを編集してください。電話番号など公開範囲を限定したい個人情報は掲載しないでください。

## 作品の追加

トップページ `index.md` の「制作作品」一覧に、作品ごとの見出しと説明を追加してください。各作品には次の情報があると伝わりやすくなります。

- 作品名、制作時期、チーム人数
- ゲームの概要と遊び方
- 自分の担当範囲と工夫した点
- 使用技術・開発環境
- 動画、スクリーンショット、配布版へのリンク

画像は `images/` に置き、Markdown から `![作品名](images/ファイル名.png)` の形で参照できます。作品カードを増やすときは、既存の作品ブロックを複製して内容を差し替えてください。

## 設定

サイト名や説明文は `_config.yml` で変更できます。変更を GitHub に push すると Pages のビルド後に反映されます。
